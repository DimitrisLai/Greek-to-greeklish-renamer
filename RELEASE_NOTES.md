# Greek to Greeklish Renamer v2.2.0 — File Filters and Windows Integration

**Dimitris Laidis · MIT License**

New: optional extension filters (All, MP3, FLAC, WAV, grouped audio or custom extensions), animated scan progress with folders/files inspected, reversible per-user Explorer context-menu integration that opens preview only, a branded app icon, Windows EXE version resources and a SHA256SUMS.txt GitHub Release asset. When a file filter is active, renaming parent folders is disabled to avoid relocating nonmatching files.

Existing capabilities are unchanged: preview-first, individually selectable changes, proposed-name editing, extension protection, safe stop, progress during Apply, detailed CSV results, undo and the original CLI.

## Downloads

- `Greeklish-Renamer-v2.2.0-Windows-Dimitris-Laidis.zip`: Windows EXE, PDF, license, quick start.
- `Greeklish-Renamer-v2.2.0-Source-Dimitris-Laidis.zip`: complete Python source, tests, build files, icons.
- `Greek_to_Greeklish_Renamer_User_Manual_v2.2.0_Dimitris_Laidis.pdf`: 10-page manual.
- `SHA256SUMS.txt`: hashes of those three files for integrity checking.

Code-signing remains pending, subject to SignPath Foundation review. An application icon and version metadata do not make the EXE digitally signed. The Explorer integration is opt-in, per-user and removable.
